# HC 및 Extra HC 판매자 활동 정보 수집

> 이 저장소는 실제 인턴 및 별도 프로젝트 경험을 설명하기 위해 새로 작성한 공개 포트폴리오입니다. 회사의 원본 소스, 데이터베이스, 고객 정보, 운영 설정, 인증정보를 포함하지 않습니다. demo.py와 예시 데이터는 2026년에 처음부터 작성한 독립적인 오프라인 재현 예제로, 2024년 실제 운영 코드를 복제하거나 당시 배포 사실을 증명하지 않습니다.

**기간:** 인턴: 2024.07~09  
**실제 업무 기술:** Python, Selenium, openpyxl, 데이터 정규화

## 배경과 해결하려던 문제

후보 계정의 활동 수치, 외부 링크 등 여러 정보를 수동으로 확인하고 비교하는 반복 작업이 있었습니다.

## 직접 수행한 작업

- 게시물 반응과 프로필의 외부 링크 등 활동 정보 수집 기능을 구현했습니다.
- 리다이렉트 URL과 제외해야 할 링크를 처리하는 로직을 개선했습니다.
- 수집 결과를 Excel에 저장하고 기존 행을 갱신하는 흐름을 만들었습니다.
- 페이지 요소 대기 및 예외 처리 기능을 보완했습니다.

## 기여 범위 및 사실 확인

실제 계정, 개인 이메일, 수집 원본, 회사의 분류 정책은 제공하지 않습니다. 실제 성장 예측 기능을 완성했다고 주장하지 않습니다.

## 공개 오프라인 데모

가상의 게시물 데이터에서 반응 요약을 계산하고 공개 가능한 형식의 기록을 생성합니다.

```bash
python demo.py
python -m unittest discover -s tests -v
```

Python 3.10 이상을 권장합니다. 외부 API 키나 실서비스 계정이 필요하지 않습니다.
